# 阿黎亲启 · 情书网页

一个带有背景音乐的网页版情书，托管于 GitHub Pages。

## 功能特性

- 🎵 **背景音乐** - 自动播放循环背景音乐
- 🎛️ **音乐控制** - 右下角浮动按钮，点击可切换播放/暂停
- 🎨 **优雅设计** - 深色主题，手写体排版
- ❄️ **动画效果** - 飘雪效果装饰
- 📱 **响应式设计** - 支持所有设备

## 音乐播放器说明

- 右下角有一个紫红色圆形按钮（♪）
- 点击按钮可以**暂停/播放**音乐
- 音乐会循环播放直到手动暂停
- 根据浏览器政策，部分浏览器可能需要用户交互才能自动播放音乐
